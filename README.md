# bareos_filedaemon

[![Docker image](https://img.shields.io/badge/docker-latest-blue.svg)](https://harbor.windmaker.net/harbor/projects/2/repositories/bareos_filedaemon)

Bareos File Daemon, the client component of the Bareos backup system. I use this image in order to manage backups of my Arch Linux hosts, like my laptop.


Packages installed:
- bareos-filedaemon (25.1.3~pre24.0e7742c39-128)

Additional features:
- Avoid the need of compile this utility from source, which is what aur package does.
